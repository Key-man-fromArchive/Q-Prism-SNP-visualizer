## Scope and decisions

- Added only synthetic fixture factories, manifest, historical JSON, usage notes,
  and a focused pytest file. No product model, scientific algorithm, threshold,
  dependency, authentication, server, or database changes.
- Reused existing `UnifiedData`, `DataWindow`, `MarkerRegion`, `ClusteringResult`
  models and production normalization/background functions. Values are literal
  arithmetic, independent of the functions under test; no private samples.
- 96/384 plate shapes, absolute pre/amplification/post windows, 2/6-ploidy markers,
  four unassigned wells, ROX on/off/unavailable, supported background modes,
  normal/contaminated/absent/incomplete/zero-reference NTC evidence are covered.
- Manifest has named 20/40-cycle numeric oracles and 12 ordered failure schedules.
  Structured QC statuses, late-response handling, and export rejection are future
  contract expectations, not implemented API behavior or proven product fixes.
- Context-free legacy payload is loadable today; its future `legacy_unknown`
  handling and report blocking must be tested in P1. Hand-authored labels are
  serialization fixtures, not genotype correctness ground truth.
