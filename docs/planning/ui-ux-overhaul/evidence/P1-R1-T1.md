## Contract and scope

- Added required provenance fields with UUID result revision, UTC-normalized
  aware completion time, absolute cycle (including zero), normalization flags,
  background/algorithm enums, JSON-object parameters, heterogeneous marker
  snapshots and nonnegative captured input revision. Parameters retain nested
  JSON values without guessing algorithm defaults; actual resolution is T3.
- `context_status` is computed from context presence; historical missing/null
  context stays `legacy_unknown`, even when incoming JSON claims `verified`.
- Migration 7 adds persisted session input revision, default zero, without
  rewriting session rows or cascading deletion of results, readings or types.
  `save_session` and startup reconstruction carry nonzero revisions. Existing
  `main.lifespan` needs no production edit; its real restore path is tested
  after closing and reopening the temporary SQLite database.
- Full result JSON and compatibility columns commit together. Failed commits
  roll back, preserve the preceding result and cannot leak into a later save.
  Publication does not increment session input revision. Empty confidences
  remain an empty JSON object rather than becoming null.
- Parent approved one existing migration test update: assert migration 6
  remains applied, not that it must forever be the latest migration. Its
  catalog/table/column/no-backfill assertions remain intact; new tests pin v7.
