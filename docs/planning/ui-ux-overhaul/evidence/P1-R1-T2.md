# P1-R1-T2 — Atomic analysis-input mutations

## Decision

Implementation verified against predecessor `1d63f41`. Effective input commands persist their complete mutation and `input_revision` together, then publish memory only after commit. Previous completed clustering results remain available; calculation capture/publication races remain P1-R1-T3 work, not a claim of this gate.

## Implemented contract

- Well-type assignment/clear/bulk replace, session ploidy, marker CRUD, layout apply and catalog attach share one synchronous transaction boundary. Composite layout/bulk commands increment once. Exact no-ops and rejected/rolled-back commands do not increment.
- Explicit override-map changes count even when the assigned value equals the imported fallback; repeating the same override is a no-op, and clearing restores the imported fallback.
- Marker names, colors and catalog linkage persist without a judgment revision change. Marker well order remains an effective input because region point construction preserves that order. Ploidy, assignments and threshold configuration remain judgment inputs.
- Optional expected revisions return 409 with current revision after authorization and domain validation. Request transport fields never enter marker records. Session information exposes current revision; sample metadata does not increment it.
- Session deletion commits database deletion before clearing all existing session/marker caches. Failure preserves both database and memory. Future T3 request-state cleanup must join this deletion boundary.
- Existing layout force/settings behavior is preserved. A successfully committed explicit clustering-request ploidy change is not undone if subsequent calculation fails; immutable calculation capture/publication is separately scoped to T3.

The short `RLock` contains no await and coordinates input writers around the existing process-global SQLite connection. It is not a multi-process guarantee or a lock around every legacy database writer/calculation. Update paths do not use session REPLACE.
