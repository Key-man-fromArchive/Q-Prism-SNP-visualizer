## Implemented contract

`reporting/result_snapshot.py` captures detached copies of the complete input, completed result/context, assignments/confidences, manual/effective provenance, current revision, merged sample names, group membership/source tags, protocol and raw filename. Authorization, explicit-domain checks, latest-request state, provenance, input revision, requested result revision and explicit-condition checks run in that order under the existing short `input_lock`. Capture and SQLite access stay on the request thread. Rendering consumes copies only, outside the lock; this remains a single-process guarantee, not distributed serialization.

Omitted cycle/ROX/background select stored conditions. Explicit cycle zero keeps the last-acquisition sentinel. Pending, missing, legacy/incomplete, stale, replaced and mismatched-condition states return their documented structured 409 codes. Failed latest analysis alone does not reject an otherwise current retained result. Captured cycle and marker IDs/names/wells/ploidies must agree with the result; invalid/overlapping membership and incomplete resolved configuration are not backfilled. Actual algorithm is not compared against the intentionally preserved legacy request echo.

CSV keeps the original ordered columns, optional Marker column and rounding precision as a prefix; appended fields identify result/input revision, time, cycle, normalization/background/algorithm, whole-run scope, marker ID/ploidy, read/call availability and the serialized analysis context. Coordinates retain their measured normalization basis. Historical raw columns remain post-background/pre-reference; passive-reference labels use explicit dye, then explicit channel, then identified legacy ROX, otherwise unknown. No raw cycle arrays or launch credentials are serialized into context metadata.

Every unified well is retained. Missing readings have blank coordinates; nonfinite readings are unavailable, never invented zeros. Genotypes use captured meaningful types/manual overrides and saved calls, never the legacy ratio fallback. Imported Unknown is neutral; explicit manual Unknown remains intentional. Outside-marker membership is independent of retained control/manual labels and always has `assignment_status=outside_marker`; without such a label its genotype is Unassigned. Other absent calls are Unknown; Empty/Omit and saved Undetermined remain intact.

Parsed/manual group source tags, raw labels and numeric row values remain available to subsequent report adapters. PDF/XLSX/ASG behavior is not implemented here. One approved annotation-only change gives the existing XLSX `qc` dictionary its correct `dict[str, object]` type, resolving a baseline mypy invariance error without changing runtime behavior.

## CSV text safety boundary

The policy follows [OWASP CSV Injection guidance](https://owasp.org/www-community/attacks/CSV_Injection): escape risky text prefixes (`=`, `+`, `-`, `@`, leading tab/CR/LF and fullwidth counterparts), use CSV quoting for embedded delimiters/quotes, and leave actual numeric values untouched. Raw snapshot labels are not modified. This is a scoped mitigation, not a universal guarantee across spreadsheet applications or save/reopen behavior; typed XLSX string cells belong to the subsequent report task.
