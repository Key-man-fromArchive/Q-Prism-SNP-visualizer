## Contract implementation

- Existing `ApiError` identity/status/payload retained, with guarded detail/code; JSON and blob errors preserve structured or legacy HTTP errors and clear authentication on 401, including unreadable bodies. Valid import 409/422 mapping outcomes remain returned; malformed primitive/array/null import payloads throw rather than masquerade as domain data.
- Additive context, QC, onset and revision types distinguish captured QC `input_revision` from `current_input_revision`; session-info has its own type. Missing GET cluster (`algorithm:null`) is distinct; malformed result envelopes reject. GET marker/type/ploidy reads do not invent revisions. Mutation revisions and DELETE query transport, flat catalog attachment, optional report/ASG conditions and revision identifiers are preserved, including explicit zero/false and previous positional arguments.
- Pure result inspection separates missing, legacy, incomplete, current, stale and unknown-revision states. Context must agree with result cycle/region definitions; requested algorithm is distinct from actual mixed/forced-threshold. Complete thresholds, ordered region membership and effective per-region settings are compared; display metadata is ignored.
- Typed `resolveAnalysisView` resolves only CURRENT request defaults from current session ploidy/cycles/markers, matching backend marker-config → request-config → default precedence, empty-region fallback, cycle-zero sentinel and region ploidy policy. It never backfills missing stored provenance.
- Analysis store uses owner/session identity, analysis generations and a separate read generation. Old/duplicate responses cannot publish; a read cannot supersede an active analysis. Latest failure retains prior results. Mutation revisions cannot move backwards; an obsolete current analysis settles pending without publishing. No invented server failure code.
- Navigation is pure whitelist serialization/validation plus generation-safe restore state. Absolute cycles obey available windows. Invalid/duplicate values carry fallback reasons. Explicit whole-run marker selection roundtrips as `marker=`; omitted marker can use validated defaults. No token/sample/raw data enters the URL.
