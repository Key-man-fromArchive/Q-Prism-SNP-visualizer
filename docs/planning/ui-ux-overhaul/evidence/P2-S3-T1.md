## Implemented contracts

- CSV, PDF, XLSX and ASG save capture one authorized detached accepted-result snapshot. Explicit export cycles, including literal zero, use `cycle_mode=absolute`; omitted mode retains legacy zero-to-latest compatibility and omitted captured context remains safe. Negative ASG cycles are rejected before a save post.
- Every server export is bound to result revision. Whole-run reports retain all rows despite selected wells, manual groups or selected-only chart filters. Input stale/unknown/refreshing, pending and legacy contexts cannot use a retained result.
- A condition mismatch offers current reanalysis, retained-result export, or cancel. Dialog actions are owner/session/entry/revision-token-bound, suppress duplicate work, cancel in-flight work, catch retry errors and turn revision conflicts into refresh-plus-reconfirmation rather than automatic replacement.
- Active PNG export uses a scoped chart registry, not a fixed DOM id. Publication waits for Plotly completion and response provenance. Registry identity binds owner/session/entry/revision, captured cycle/reference/background, exact rendered visible scope and render generation. It is invalidated before new rendering and checked again after PNG encode/caption; logout, navigation, filter replacement and cancellation cannot trigger a late download.
- Stored PNG intentionally moves to captured conditions while `exportRestoring` suppresses only automatic analysis. The matching response may render/export; the pause is cleared on success, failure, cancellation and session replacement. The settled scheduler consumes this restoration transition, so lifting the pause does not reanalyse and overwrite the accepted result.
- Actual PNG captions carry scope, cycle, reference/raw basis, background, visible wells or marker scope, revision and analysis timestamp. Blob downloads use safe filenames, owner checks and URL cleanup. Modal portal/inert behavior and KO/EN strings cover the decision flow.
