## Implemented contract

- Global shortcuts yield to prevented events, composition/229, editable fields, native widgets, dialogs/menus, Alt/AltGr and repeated keys. Platform-primary Ctrl/Cmd only; analysis readiness and selection authorize mutations. Cycle navigation uses actual sparse values, including zero.
- Global export enters the same Header validation/mismatch flow as the button. Global undo/redo is deliberately not consumed until P3-S2 shared history/CAS exists.
- Plate and result grids share roving focus, reachable headers, arrows/Home/End, Shift rectangle, Enter/Space toggle and Escape clear. Native pointer capture starts only after a drag; plain/modifier/range selection remains consistent. Grid rows, names, selected state and live counts are explicit.
- Primary/workspace tabs provide directional navigation and linked panels. Overflow routes remain menu navigation, not falsely labelled tabpanels.
- Popup and shortcut assignments share a pending owner/session/entry guard; failure retains selection and announces the error in KO/EN. Late or unmounted completion cannot clear new selection. Popup success closes only after accepted completion.
- Help uses the shared modal/inert/focus-return infrastructure; its scroll area is keyboard reachable. Menu navigation skips disabled items; every popup action participates in menu focus.
