## Implementation

- URL whitelist remains exactly `session/tab/surface/marker/cycle`. Discrete navigation pushes; cycle changes and export-restoration settlement replace with deduplication. Accepted normal upload/reopen writes its initial URL. Popstate restores without rewriting. Prefix and unrelated hash survive; ASG credentials are removed.
- Session-independent project/references/library tabs (users for admins) restore without session-data requests. Their URLs contain only `tab`; unavailable/session-required tabs fall back without rewriting. Non-user generation invalidations never emit history entries.
- Version-1 calculation cache uses escaped authenticated-owner + session keys in sessionStorage. Explicit boolean/enum/finite/range checks and field copying exclude tokens, sample names, raw data and arbitrary context. Logout/user replacement clears only the previous owner's cache. Global preferences never override session cache/context/default precedence.
- Authorized session admission precedes the existing single workspace loader. Settings, actual cycle and data-window apply before one ready publication. Old owner/session-entry/navigation-generation responses cannot publish. Reopened runs never implicitly analyze; fresh uploads retain their existing first-analysis policy.
- App ROX initialization is removed: valid cached false survives. Export restoration remains a distinct render-allowed pause. Initial loading, permission/not-found/network errors and retry are localized and do not expose stale charts or server error bodies.
- Auth bootstrap shares one request across StrictMode replay and checks auth generation before publication; late launch completion cannot undo logout. Launch failures use fixed localized text.
