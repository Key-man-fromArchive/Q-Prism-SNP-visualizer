# P3-S4-T1 — Marker scope and Empty/Omit

Baseline: `4e21970`, branch `ux-followup/p3-recovery`. Scientific calculations, parsers, thresholds, origin estimation and QC denominators are unchanged.

## Contract implemented

- Authenticated upload/import/example and session-info responses expose a defensive copy of the exact `UnifiedData.wells` as `well_ids`. Reopened metadata reaches the session store behind the existing owner/entry/restore guard.
- Zero persisted/nonempty markers, including empty local drafts, means whole-plate analysis. Actual run inventory, not the physical grid, current cycle, selected group or plot visibility, determines counts. Missing legacy inventory is explicitly unknown.
- Marker membership is deduplicated and intersected with actual input IDs. Empty and Omit counts are independent, potentially overlapping with unassigned membership; eligibility uses set exclusion, not an additive exclusion total. Numeric zero is never a missing-data test.
- Shared bilingual summary appears in setup and analysis. Sparse A1/P24 inventory produces 384 geometry without claiming 384 input wells. Omit remains focusable/selectable and recoverable using the existing shared type command.
- Initial/failed marker reads cannot announce whole-plate scope. Every external reload immediately withdraws the old scope; latest-request and identity guards reject obsolete reads. A confirmed local edit invalidates an older read without losing the newly published marker state.
