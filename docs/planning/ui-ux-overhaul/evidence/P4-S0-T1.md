## Implemented contract

- Header identity and action groups wrap deliberately; full user/session values remain available through titles. Narrow linked-ASG identity uses a keyboard-operable native disclosure; desktop displays the full context. Long unbroken aliases wrap without hiding actions.
- Removed the global `.hidden!important` collision with responsive Tailwind display utilities. Primary tabs wrap while retaining roving navigation and overflow-menu ownership. Shared grid foundation has one column below 1280px and two above; the obsolete `lg` override is removed.
- Header QC details are bounded by the header viewport. Shared dialogs have a viewport-relative maximum height, internal scrolling and wrapping footer, retaining existing focus trap/return, Escape, inert background and scroll lock.
- Project action uses the shared dialog and owner/entry guarded operations. Late responses cannot reopen old context; safe localized errors replace private transport text. A successful add followed by failed list refresh remains a confirmed success with a refresh error; retry reloads only the list.
