# P4-S2-T1 — Actionable quality warnings

Baseline `255523b`. Frontend navigation/presentation only; no parser, threshold, origin, backend QC denominator, assignment or analysis algorithm changes.

## Implemented contract

- Keyboard-operable warning links resolve authorized current inventory, actual cycle and marker membership. Assigned wells open the correct analysis marker; partitioned unassigned wells open Plate Setup and its actual-well inspector. Whole-plate runs remain whole plate. Invalid/ambiguous/stale targets produce localized safe feedback without guessing a well.
- An owner/session/entry-pinned temporary reveal exposes only the existing target point through group, Empty/Omit and selected-only filters. User settings and roles remain unchanged. Single and marker scatter use the same display predicate for traces, bounds and counts; marker membership precedes reveal, and missing readings are never fabricated. Clear/Return restores the original view/selection and logical focus.
- Curve quality is explicitly full-curve, unversioned run/SID and requested-ROX diagnostics, independent of genotype availability/revision/background. NTC navigation validates actual input/result revisions plus cycle, ROX and background; its persistent notice labels every condition, including cycle zero. Live condition changes invalidate admission/reveal rather than changing settings.
- Same-URL consecutive targets use allowlisted scalar `history.state`, not new URL parameters. No sample names, tokens or raw data are copied. Live Back/Forward is latest-request guarded; reload ignores transient target state. Owner/session changes and restoration clear leases. Fresh marker metadata is published through guarded subscriptions so old reads cannot replace accepted scope.
- Navigation moves focus to the exact mounted well, announces pending/error/source/basis and offers Return. No automatic analysis, suggestion or type mutation is triggered by jumps, history or Return. Subsequent deliberate analysis edits retain their existing scheduling behavior.

## RED-first repairs

Focused regressions reproduced missing warning actions, stale ROX/revision/background admission, hidden Omit targets, old marker reads, rapid overlapping popstate cleanup and curve navigation incorrectly depending on genotype results. Each was fixed before the final run. Component regressions cover both actual scatter adapters (reveal then clear, immutable settings/assignments), not just the pure predicate. KO/EN scope tests cover requested ROX false/true and NTC cycle0/background/revisions. QualityTab now uses a localized retry error instead of displaying raw server text.

Browser RED exposed a missing Plate Setup selected-address display and asynchronous QC refresh readiness in the test. The former now displays the actual selected address; the latter waits for the real refreshed response. Assertions were not weakened. A failed intermediate component run caused by leaked test state/incomplete Plotly mocks was repaired in test setup; subsequent full runs are clean.
