- Shared `chart-semantics` drives category symbols, localized call descriptions, cell text contrast and plot appearances. Diploid Hom-1/Hom-2 labels no longer resemble A1/A2 well addresses. - Single and marker plots use distinct category symbols, theme-aware outlines and original-to-minimal contrast correction. Selected/reference-warning points retain category symbols and add thicker outlines plus localized hover text; no unused flagged-symbol promise is made. Threshold traces use a stable UID, independent of localized names.
- `normalizationReported` is true only for an explicit boolean response `normalization.applied`, and resets with data. Requested/applied/raw-fallback/unknown reading labels are separate from amplification curves, whose response does not report normalization provenance. Numeric fallbacks are preserved; no curve provenance is inferred from scatter responses.
- KO/EN presentation strings cover recommended analysis, threshold/hover/call descriptions, missing samples and excluded/scope states. Existing analysis pending/error/stale/unknown messages remain localized. This is a touched-core inventory, not a claim that every unrelated administration/legacy screen has been translated.
