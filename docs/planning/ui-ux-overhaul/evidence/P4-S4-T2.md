## Implemented contract

- Library layouts and marker-catalog lists validate the complete consumed response shape before publication.  A malformed successful response (including nested marker wells, threshold settings, `well_types`, `sample_ids`, or identifiers) keeps the last known-good list, emits a safe localized retryable error, and never renders untrusted nested values.
- Read, mutation, and destructive-confirmation ownership are separate.  Confirmation begins before a dialog, while the mutation ticket begins only after confirmation; owner/session/entry replacement and duplicate approval cannot publish stale results or leave a shared loading state stuck.
- Project concordance accepts the wire-level nullable `percentage`; unavailable values are rendered as localized `Unavailable`/`산출 불가` and exported with the same safe wording.  Nonzero concordance remains covered by realistic CSV tests.
- Library, catalog, project, users, references, and compare surfaces have bounded responsive layouts, safe permission/load errors, keyboard tab/dialog behavior, full long identifiers (including session-ID title/ARIA affordances), and a named compare plot region.  Existing backend permission checks, delete confirmations, and Layout 409 force semantics remain intact.
