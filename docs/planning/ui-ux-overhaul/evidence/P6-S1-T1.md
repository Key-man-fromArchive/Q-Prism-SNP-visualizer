# P6-S1-T1 — NTC 기준 축 offset 설정

## 구현 결과

기본으로 유지해 온 `axisMode: zero`의 저장 키는 하위 호환을 위해 유지하고,
화면 의미를 NTC 기준 모드로 변경했다. 전체/마커별 산점도 모두 ratio origin을
기준으로 X/Y offset을 독립 적용한다. 유한한 실제 데이터 최솟값과
`origin - offset` 중 더 작은 값을 하한으로 사용하므로 음수 광학값도 잘리지 않는다.
raw RFU와 정규화 표시의 단위가 다르므로 `(100,100)`과 `(0.1,0.1)`을 별도
저장한다. 예를 들어 origin `(1000,2000)`과 raw offset `(100,100)`은
`(900,1900)`에서 시작한다. Reset은 현재 표시 basis만 기본값으로 되돌린다.
