# P7-S1-T1 — 웰 선택 스크롤·marquee 상호작용 정리

## 구현 결과

분석 `PlateView`와 `PlateSetupTab`의 웰 선택 surface를 Windows 바탕화면과
유사한 pointer marquee 동작으로 정리했다.

- 데스크톱 분석 plate 영역은 고정 `max-height`와 `overflow: auto`를 제거하고,
  세로는 콘텐츠가 자연스럽게 확장되며 384웰은 가로로만 스크롤되도록 했다.
- 두 화면 모두 5px 이동 threshold와 pointer capture/release/cancel을 유지한다.
  Plate Setup은 웰 중심 좌표를 실제 marquee와 비교해 역방향 드래그도 동일하게
  선택한다. Ctrl/Cmd additive, Shift 범위, 단일 클릭 toggle은 기존 계약을 유지한다.
- marquee는 pointer-events가 없는 반투명 blue fill과 명확한 blue border로
  표시한다. selection surface에는 `select-none`과 left-button default 방지가
  적용되며, 마커/레이아웃 폼 입력 영역에는 영향을 주지 않는다.
- 384웰 Setup grid는 최소 가로 폭을 보장해 작은 화면에서 잘리지 않고
  wrapper의 horizontal overflow를 사용한다.
