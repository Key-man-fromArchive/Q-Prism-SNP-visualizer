# Release v1.4.0

**Date:** October 2, 2026

## New Features

### StepOnePlus Instrument Support
- Full support for Applied Biosystems StepOnePlus `.eds` raw files
- Automatic detection of 7 read-cycle data: Pre-read, PCR 36–40 (40°C), and Post-read
- First analysis view defaults to Amplification cycle (PCR 36)
- Session restore preserves initial cycle selection

### Marker Allele Names
- Edit allele names for each marker in the Plate Setup tab
- FAM/VIC/HEX channel assignment with per-dye naming
- Automatic population from instrument files (StepOnePlus and QuantStudio)
- Display names in scatter plots, plate views, and all exports
- Confidence: 2-multiplex (WT/MT) mode

### ROX Auto-Normalization
- ROX passive reference normalization enabled by default when available
- Quality check confirms ROX signal stability across wells
- Adjustable reference in Cycle Control settings
- Supports ROX normalization across all supported instruments

### Result Exports: Per-Marker Selection
- **PDF Report** — Scatter plot and plate map for each selected marker with genotype summary
- **PowerPoint Presentation (NEW)** — Separate slides per marker, overall results table, 16:9 aspect ratio
- **Scatter Image Bundle (NEW)** — Individual PNG images per marker in ZIP archive with safe filenames
- **Excel/CSV Spreadsheet** — New "Allele Call" column showing allele pair names (e.g., "WT/WT", "WT/MT", "MT/MT")

All exports preserve current marker allele names. Use the export menu to filter by marker or download all.

### Improved Analysis Display
- Scatter plot titles include marker name and cycle label (e.g., "QPrism1 · Amplification 1/5 (PCR 36)")
- Axes labeled with allele names and normalization channel
- Legend shows allele frequencies
- Cycle control displays actual PCR cycle number and temperature (e.g., "PCR 36, 40°C")
- Well labels visible on plots with ≤48 wells

### Multi-Format Plate Mapping
- Plate map shows marker boundaries and abbreviations
- Per-marker plate map with highlighted wells in PDF and PowerPoint
- Marker layout visualization in scatter exports

## Improvements

- Enhanced scatter plot readability with improved typography and layout
- Han-script (Korean) font support in reports and exports
- Better aspect ratio control for charts (4:3 and 1:1 options)
- Consistent allele naming across all UI surfaces and outputs
- Marker selection preserved when retrying on condition mismatch

## Bug Fixes

- Fixed marker allele name display in analysis results after editing
- Snapshot captures now record marker allele names at analysis time
- Plate view reflects current marker configuration

## Known Limitations

- **Batch screen:** allele names shown per plate when every marker on the plate shares one set (FOLLOWUP-BATCH-LABELS, resolved 2026-10-03)
- **StepOnePlus 48-well plates:** Not supported; 8×12 96-well format only
- **Scatter plot well labels:** May overlap with ≥64 wells per marker; consider zooming or exporting

## Dependencies

New dependencies for PowerPoint and image export:
- `python-pptx` 0.6.24
- `lxml` 5.4.0
- `XlsxWriter` 3.2.2
- `Pillow` 10.4.0
- `typing_extensions` 4.14.2

See `snp-analyzer/requirements.txt` for full version pinning.

## Migration Notes

### From v1.3.x

- Existing sessions restore without changes; allele names remain as "Allele 1" / "Allele 2" until edited
- Export formats (PDF, CSV, XLSX) maintain backward compatibility
- New PPTX and PNG export formats are opt-in from the export menu

### Database

- Database schema updated to v11; automatic migration on first session load
- New `allele_labels_json` column in `marker_regions` table for name persistence
- `metadata_json` extended to preserve `read_labels`, `default_cycle`, and `has_amplification_curve` across session restores
